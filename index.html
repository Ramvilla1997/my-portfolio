Case studies

Two products, end to end.

01 · SpendVoice

Logging an expense should take one sentence.

Most expense apps are forms. SpendVoice takes a sentence, shows a preview, and saves only after you confirm, so a misheard amount never gets recorded silently.

The amount is stored as whole cents. The app runs offline as an installable web app, and data stays in the browser.

Decisions
Preview before save, integer cents, IndexedDB behind a repository, a strict Content Security Policy.
Verified
54 unit and component tests, production build, browser check at phone width.

02 · Analytics dashboard

A dashboard that refuses to show a wrong number.

Every payload is parsed against a schema before the UI sees it. A malformed response fails loudly instead of quietly rendering a bad revenue figure.

Decisions
TanStack Query for server state, Zod at the boundary, a mock API behind an interface so a real backend can replace it.
Verified
15 tests covering metrics, the mock contract, and page behaviour, including a retry after failure.
